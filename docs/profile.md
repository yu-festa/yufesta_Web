# 프로필 화면

- 메인 헤더의 사람 아이콘 → `/#profile`.
- 로그인 사용자는 `GET /api/v1/auth/me`의 `data.displayName`, `data.profileImageUrl`로 소셜 이름과 프로필 사진을 표시합니다. 표시 이름이 비어 있으면 `YU FESTA`, 사진이 없거나 로딩에 실패하면 기본 프로필 이미지를 표시합니다.
- 인스타팅 신청이 없어도 소셜 프로필을 표시합니다. 신청 내역 조회가 지연되거나 실패해도 소셜 프로필은 갱신됩니다.
- 인스타그램 아이디와 인스타팅 참여 내역은 본인 신청 조회에서 가져옵니다. 신청 닉네임은 소셜 표시 이름과 별도로 참여 내역에 보존합니다.
- 참여 내역의 `신청 정보 보기`를 펼치면 닉네임·인스타그램·관심 키워드를 확인할 수 있습니다.
- 비로그인 사용자는 로그인 화면으로 이동합니다. 개발 중 `.env.local`에 `VITE_PROFILE_PREVIEW=true`를 설정하면 예시 프로필을 볼 수 있으며 기본값은 비활성화입니다.
- 예시 프로필은 실제 로그인 세션이 아니며 화면에 미리보기임을 표시합니다. 로그인 사용자가 있으면 예시 데이터보다 우선합니다.
- 분기 검증: `node --test tests/profile.test.ts`.
