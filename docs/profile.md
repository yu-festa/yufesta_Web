# 프로필 화면

- 메인 헤더의 사람 아이콘 → `/#profile`.
- 현재 API가 없어 예시 이름 `가을축제`, 기본 프로필 이미지, 인스타그램 아이디 및 인스타팅 참여 내역 1건을 표시합니다. 화면에 예시임을 표시합니다.
- 참여 내역의 `신청 정보 보기`를 펼치면 닉네임·인스타그램·관심 키워드를 확인할 수 있습니다.
- 예시 프로필은 실제 로그인 세션이 아니며, 기존 인스타팅 신청 버튼의 로그인 이동을 변경하지 않습니다.
- `.env.local`에 `VITE_PROFILE_PREVIEW=false`를 넣고 개발 서버를 재시작하면 비로그인 사용자의 프로필 버튼과 `/#profile` 직접 접속 모두 로그인 화면으로 이동합니다. 현재 기본값은 요청에 따라 미리보기 활성화입니다.
- API 연동 시 `getCurrentProfileUser()`를 실제 인증 세션 및 사용자별 참여 내역 조회로 교체합니다. 로그인 사용자가 있으면 예시 데이터보다 우선합니다. 서버에서도 인증·인가를 검증해야 합니다.
- 실제 신청 저장은 아직 연동되지 않았으므로 신청 UI에서 완료한 내용이 이 예시 참여 내역에 추가되지는 않습니다.
- 분기 검증: `node --test tests/profile.test.ts`.
