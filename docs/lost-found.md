# 분실물 게시판

- `/main#lost`는 `GET /api/v1/lost-items?size=50`의 공개 목록을 보여줍니다. 검색과 분실/습득 구분은 받은 최근 50건 안에서 적용합니다.
- 기존 게시판의 제목·내용 입력 화면을 유지합니다. 서버에는 둘을 줄바꿈으로 합친 최대 100자의 `description`, 장소, 선택한 발생 시각을 `POST /api/v1/lost-items`로 보냅니다. 기존 서버 글처럼 줄바꿈이 없는 설명은 제목으로 표시합니다. 작성한 글의 해결 처리와 삭제는 각각 `PATCH /lost-items/{id}/resolve`, `DELETE /lost-items/{id}`를 사용하며 서버가 작성자 권한을 검사합니다.
- 상세 API가 없어 `/main#lost/post/{id}`는 최근 50건 목록에서 해당 글을 찾습니다. 범위 밖이거나 비공개·삭제된 글은 표시할 수 없습니다.
- 사진 업로드와 댓글 API가 없어 해당 입력 UI는 숨겼습니다. 이전 버전의 IndexedDB 글/사진/댓글은 서버 글로 이관되지 않습니다.
- 로그인한 사용자는 일반 분실물 글을 `POST /api/v1/content-reports`로 신고할 수 있습니다. 운영자 화면에서는 공식 습득물 등록, 해결 처리, 공개/숨김, 신고 검토를 제공합니다.
- `GET /api/v1/auth/me`의 비로그인 401은 목록 읽기 실패가 아닙니다. 글쓰기·신고는 로그인과 CSRF 쿠키가 필요합니다.
