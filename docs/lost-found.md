# 분실물 게시판

- 메인 `분실물 확인` → `#lost`, 글쓰기 → `#lost/write`.
- 게시글 클릭 → `#lost/post/{id}` 전용 상세 화면. 새로고침·주소 직접 진입·브라우저 뒤로 가기를 지원하며, 없는 글은 게시판으로 돌아가는 안내를 표시합니다.
- 현재 브라우저의 IndexedDB `yufesta-lost-found` / `posts`에 글과 사진을 함께 저장합니다. 같은 브라우저·같은 사이트 주소에서 새로고침 후에도 유지됩니다. 다른 기기·브라우저와 공유하지 않으며 사이트 데이터를 지우면 삭제됩니다.
- 초기 게시글은 비어 있습니다. 예시 글이나 고정된 게시글 수를 실제 데이터로 표시하지 않습니다.
- 찾고 있어요 / 주웠어요 필터, 제목·장소·내용 검색, 최신순 목록, 상세 내용과 첨부 사진 보기를 제공합니다.
- 상세 화면은 익명 작성 정보·본문·장소·첨부 사진·댓글 목록·하단 고정 댓글 입력창으로 구성합니다. [에브리타임 공식 앱 화면](https://play.google.com/store/apps/details?id=com.everytime.v2&hl=ko)의 커뮤니티 배치를 참고하고 사이트의 파란색을 적용했습니다.
- 댓글은 익명으로 입력하며 최대 500자입니다. 빈 댓글·공백 댓글을 막고 저장 중 중복 클릭을 방지합니다. 실패하면 입력을 유지합니다.
- IndexedDB 버전 2에서 기존 `posts`를 유지하고 `comments` 저장소와 `postId` 인덱스를 추가합니다. 댓글도 현재 브라우저에만 저장하며 새로고침 후 유지됩니다. API·로그인 연동 및 다른 사용자와의 댓글 공유는 아직 제공하지 않습니다.
- 제목 80자, 장소 100자, 내용 3,000자까지 입력할 수 있습니다. 필수 항목에는 공백만 입력할 수 없습니다.
- 사진은 선택 사항이며 JPG/PNG/WebP, 장당 최대 10MB, 최대 5장입니다. 브라우저에서 긴 변 최대 1,280px로 축소해 저장합니다. 미리보기·개별 제거를 지원합니다.
- IndexedDB 쓰기 트랜잭션이 완료된 후에만 등록 성공을 표시합니다. 실패하면 작성 내용과 사진을 유지하며 재시도할 수 있습니다.
- 테스트: `npm run test:lost`, `npm run build`, `npm run lint`.
