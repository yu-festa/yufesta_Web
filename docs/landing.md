# 축제 사전 랜딩 페이지

## 화면과 공개 일정

- `/`: 2026년 10월 1일 00:00:00 한국 시간 전에는 랜딩, 이후에는 기존 메인 화면.
- 브라우저를 열어둔 채로 카운트다운이 끝나도 새로고침 없이 메인으로 전환합니다. 창에 다시 돌아왔을 때도 현재 시각을 확인합니다.
- `/main`: 기존 메인 화면을 미리 확인하는 직접 접속 주소. 기존 상세 화면과 `/instating/apply`도 유지합니다.
- 스플래시 동작은 유지합니다.
- 기준 시각은 `src/utils/festivalLaunch.ts`의 `FESTIVAL_START_AT`에서 관리합니다. 메인 배너의 인스타팅 결과 발표 타이머와는 별개입니다.
- 랜딩 페이지 메뉴는 페이지 내부 섹션으로 이동합니다. 서비스 카드와 FAQ는 클릭하거나 키보드로 상세 설명을 펼칠 수 있습니다.

## 검증

`node --test tests/festival-launch.test.ts`로 기준 시간대, 만료 직전·정각·이후, 백그라운드 경과 및 잘못된 개발용 시각을 검사합니다.

실제 브라우저 전환 확인이 필요하면 개발 서버에서만 `VITE_FESTIVAL_START_AT`에 시간대가 포함된 가까운 미래의 ISO 시각을 지정하고 재시작합니다. 예: `2026-09-17T16:30:00+09:00`. 프로덕션 빌드는 이 값을 무시하고 공식 일정을 사용합니다. 테스트 후 환경변수를 제거합니다.

현재 공개 전환은 브라우저 시계 기준입니다. 정확한 서버 시각 동기화 및 서버 차원의 공개 제한은 API 연동 시 별도로 구현합니다.
