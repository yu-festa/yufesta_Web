# 축제 주변 화장실 조사 기록

자료 확인일: **2026-09-16**. 현장 실사 및 축제 당일 운영 확인은 하지 않았습니다.

조사 범위는 기존 지도에 표시된 천연잔디축구장·천마로 시계탑 주변에서 중앙도서관·이종우과학도서관 일대까지입니다.
공식 캠퍼스맵, 도서관 층별 시설안내, 장애학생지원센터, 영대신문 및 한국관광공사 자료를 확인했습니다.
**주변 건물의 모든 화장실을 확보한 자료가 아닙니다.** 기숙사·제한 출입 연구시설은 축제 방문객 안내에 포함하지 않았습니다.
핀은 [공식 캠퍼스맵](https://www.yu.ac.kr/main/intro/campus-map.do)의 건물 대표 좌표이며, 실내 화장실·출입구 좌표가 아닙니다.

## 도면에서 실내 위치까지 확인한 시설

도면의 화장실 아이콘을 읽어 주변 시설을 설명했습니다. 도면에 붙은 원형 숫자는 시설 설명 번호이며 **호실 번호가 아닙니다**.
호실 앞 위치는 확보하지 못했으므로 UI에 임의의 호실 번호를 넣지 않습니다. 도면은 복제 배포하지 않고 공식 원본으로 연결합니다.

## 상세 안내를 확보하지 못한 주변 건물

상경관 B02, 사회과학관 B05, 디자인관 A06, 국제교류센터 A02는 공식 캠퍼스맵의 강의실·사무실 목록과 공개 검색 결과에서 실내 화장실 도면이나 호실 앞 위치를 확보하지 못했습니다.
과거 단수 공지나 개별 수리 민원은 현재 층별 배치를 확인할 자료로 사용하지 않았습니다. 목록에서 미확인 상태로 보여주며, 임의의 화장실 핀·층·호실을 만들지 않습니다.

## 데이터 갱신

### 2026-09-18 카카오맵 적용 후 좌표 대조

공식 캠퍼스맵 원문의 `campusList`에 있는 `bGPS`(경도, 위도)를 다시 읽어 화장실 8개 건물과 천연잔디축구장·천마로 시계탑 좌표를 대조했습니다. 기존 데이터 10곳 모두 일치하여 좌표를 임의로 옮기지 않았습니다. 학생지원센터 1층 장애인 화장실 안내도 공식 캠퍼스맵에서 재확인했습니다.

공연장 선택 후 반경 500m 안의 확인된 화장실 건물을 직선 거리순으로 표시합니다. 거리는 두 대표 좌표 사이의 대권 거리이며 실제 보행 거리가 아닙니다. 위치 권한을 허용하면 현재 위치와 선택한 건물 핀을 함께 표시하고, 두 좌표 사이의 직선 거리를 브라우저에서 계산합니다. 경로 API는 사용하지 않으며, 실내 위치는 기존 층별 안내에서 확인합니다. 지도 제공자를 바꾸는 것만으로 실내 화장실 좌표나 축제 당일 개방 정보가 추가되는 것은 아닙니다.

`src/data/restrooms.ts`에서 건물과 층별 항목, 출처를 함께 관리합니다. 현장 또는 공식 자료를 추가 확인한 뒤에만 위치·남녀 구분·장애인 이용 정보를 갱신합니다.
자료 확인일과 운영 확인은 구분해야 합니다. 현장 확인 전에는 개방 중으로 표시하지 않습니다.
