# 인스타팅 신청 UI

- 직접 접속: `/instating/apply` (개발 서버 기본 주소: `http://localhost:5173/instating/apply`)
- 1단계: 닉네임, 인스타그램 아이디, 성별, 나이대
- 2단계: 관심 태그 최대 3개, 선호 공연 선택, 40자 소개
- 3단계: 입력 정보 확인 및 필수 동의, 완료 버튼
- 완료: 하트 두근거림 모션, 결과 발표 시각 안내, 홈 이동
- 이전 단계 버튼을 누르면 입력값이 유지됩니다. 새로고침 시 처음부터 시작합니다.
- 동작 줄이기 환경설정에서는 하트 애니메이션을 재생하지 않습니다.

신청·수정은 로그인 후 서버 API에 제출합니다. 필수 동의와 입력값을 검사하고, 서버에서 성공 응답을 받은 뒤에만 완료 화면을 표시합니다.

공연 선택지는 현재 회차의 `GET /api/v1/match/slots` 응답을 사용합니다. 선택한 `wantedSlotId`는 신청·수정 요청에 포함되며, 이월 후 `needsSlotReselect`가 true이면 다시 선택하도록 안내합니다. 약관 본문 및 개인정보 처리·공개 정책은 운영 문서와 일치하는지 별도 확인이 필요합니다.

배포 서버에서는 `/instating/apply` 새로고침 요청을 `index.html`로 전달하는 SPA fallback이 필요합니다. Vite 개발 서버는 이를 지원합니다.
