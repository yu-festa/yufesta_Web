# 인스타팅 신청 UI

- 직접 접속: `/instating/apply` (개발 서버 기본 주소: `http://localhost:5173/instating/apply`)
- 1단계: 닉네임, 인스타그램 아이디, 성별, 나이대
- 2단계: 관심 태그 1~3개, 희망 공연, 40자 소개, 여러 명 매칭 선택
- 3단계: 입력 정보 확인 및 필수 동의, 완료 버튼
- 완료: 하트 두근거림 모션, 결과 발표 `시간 미정`, 홈 이동
- 이전 단계 버튼을 누르면 입력값이 유지됩니다. 새로고침 시 처음부터 시작합니다.
- 동작 줄이기 환경설정에서는 하트 애니메이션을 재생하지 않습니다.

현재는 화면 확인용 UI입니다. 로그인 검사, 서버 제출, 개인정보 저장, 실제 매칭은 수행하지 않습니다. 완료 버튼은 필수 동의 검사 후 완료 화면만 표시합니다. 홈 배너의 기존 로그인 이동은 유지합니다.

공연 선택지는 현재 타임테이블의 예시 데이터를 공유합니다. 실제 서비스 연결 시 공연 목록, 결과 발표 일정, 약관 본문 및 개인정보 처리·공개 정책을 확정하고 서버 API의 성공 응답 이후에만 완료 화면을 표시해야 합니다.

배포 서버에서는 `/instating/apply` 새로고침 요청을 `index.html`로 전달하는 SPA fallback이 필요합니다. Vite 개발 서버는 이를 지원합니다.
