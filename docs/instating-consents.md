# 인스타팅 필수 동의 모달

신청 마지막 단계의 개인정보·서비스 이용약관·만 19세 이상 항목 제목을 누르면 각각의 모달이 열립니다. 기존 체크박스로 직접 동의하거나 `전체 동의`할 수도 있습니다.

- 내용을 여는 것만으로 동의하지 않습니다. `동의하고 닫기`를 누르면 해당 항목만 체크합니다.
- 닫기 버튼과 Escape는 동의 상태를 변경하지 않습니다. 다시 열면 이미 체크된 상태도 유지됩니다.
- 모달을 열면 배경 조작·스크롤을 막고 키보드 초점을 모달 안에 유지합니다. 닫으면 열었던 버튼으로 초점을 돌립니다.
- 긴 본문만 스크롤하며 제목·닫기·동의 버튼은 모달 안에 유지합니다.
- 세 항목 모두 동의해야 신청할 수 있습니다. 신청 수정에는 기존과 같이 동의 항목을 다시 요구하지 않습니다.
- 실제 서버 신청은 기존 신청 완료 버튼에서만 실행합니다. 동의 버튼 자체는 신청을 전송하지 않습니다.

## 사용자 확인 정책

2026-09-29 사용자 답변에 따라 운영 주체는 **YUFESTA**, 연락처는 **별도 표기하지 않음**, 신청 정보와 인스타그램 아이디 삭제 시점은 **축제 종료 7일 뒤**로 반영했습니다. 마이페이지의 종료 안내에도 동일한 삭제 시점을 표시합니다. 실제 파기 작업은 백엔드에서 실행해야 합니다.

서비스 이용약관은 이용자 간 자발적 연락·만남·거래에서 발생한 문제 중 운영자에게 귀책사유가 없는 사항의 책임을 제한합니다. 운영자의 고의·중과실이나 법령상 배제할 수 없는 책임은 면제하지 않습니다. 서비스 약관 본문에서 이 두 문단을 함께 강조합니다.

## 운영 전 검토 사항

본문은 요청에 따라 작성한 초안이며 법률 검토를 대체하지 않습니다. 개인정보 처리 고지의 충분성, 매칭 상대에 대한 정보 제공의 별도 동의 필요 여부 및 책임 제한 범위는 실제 운영 방식과 함께 검토해야 합니다.

- [개인정보 보호법 제15조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398563): 목적, 항목, 보유·이용 기간, 거부권과 불이익 안내.
- [약관의 규제에 관한 법률 제7조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025032399): 고의·중과실 면책 등 금지.
- 기존 API 계약인 `termsVersion`, `privacyVersion`, `ageConfirmed` 전송을 유지합니다. 두 버전 값은 현재 `2026-09-01`이며, 새 본문을 운영에 적용할 때 백엔드의 약관 원문·버전과 일치하는지 확인해야 합니다. 이 작업에서는 임의로 서버의 동의 버전을 바꾸지 않았습니다.
